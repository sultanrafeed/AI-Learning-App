Three ways to show KB ⊨ γ:
  1. Model checking: list all 2ⁿ rows; keep rows where KB is true; γ must be true in all of them. KB = P ∧ (P ⇒ Q): only row P=T, Q=T → Q true → entails. KB = P ⇒ Q does NOT entail Q (row F, F). 5 symbols → 32 models.
  2. Theorem proving with rules: Modus Ponens (α ⇒ β, α ⊢ β), And-elimination (α ∧ β ⊢ α), plus the equivalences.
  3. Proof by contradiction with resolution: add ¬γ (negate ONLY the query) → convert everything to CNF → resolve pairs with complementary literals → empty clause □ ⇒ KB ⊨ γ (α ⊨ β iff α ∧ ¬β is unsatisfiable).
Resolution: \((\ell \lor A),\ (\neg\ell \lor B)\ \vdash\ A \lor B\) · CNF steps: ① remove ⇔ ② remove ⇒ ③ push ¬ inward ④ distribute ∨ over ∧
C1 P, C2 ¬P ∨ Q, C3 ¬Q (negated query) → C1+C2 = Q → Q + C3 = □. (P∨Q∨R)+(¬Q∨S) = P∨R∨S · (A∨B)+(¬A∨B) = B · (¬A∨B)+(A∨C) = B∨C.
CNF: A ⇒ (B∧C) = (¬A∨B)∧(¬A∨C) · ¬(A∨B) ⇒ C = A∨B∨C · B₁,₁ ⇔ (P₁,₂ ∨ P₂,₁) = (¬B₁,₁∨P₁,₂∨P₂,₁) ∧ (¬P₁,₂∨B₁,₁) ∧ (¬P₂,₁∨B₁,₁).
Literal = atom or its negation · clause = OR of literals · CNF = AND of clauses · complementary = P and ¬P · satisfiable = true in some model; unsatisfiable = none (P ∧ ¬P); valid = all. Proposition = declarative statement, true or false (not questions or commands).

Term = names an object (constant John, variable x, function Father(John)); predicate = true/false (Brother(Richard, John), arity 2; zero-ary = propositional symbol like Raining). Universal instantiation: replace x by ANY ground term, many times (Student(Mia) ⇒ Studies(Mia)). Existential instantiation: replace by a BRAND-NEW constant, once. Then propositionalise → problem: too many ground instances. King(John) ∧ Greedy(John) + ∀x King ∧ Greedy ⇒ Evil → Evil(John). Deductive = general rule → certain conclusion; inductive = pattern → probable ("Leo will probably pass"). Logical inference applies rules; ML inference applies a trained model.

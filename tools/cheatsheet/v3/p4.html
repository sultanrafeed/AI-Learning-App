An RNN reads a sequence one step at a time and keeps a running memory h. New memory = squash(input × its weight + old memory × its weight).

22Scaled dot-product attentionLecture 8 · key points↑ index
Attention = a soft search. The query asks; each key says what a token is about; the weights say how much each token matters; the output mixes the VALUES with those weights.
\(\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V\)
  1. Scores sᵢ = q · kᵢ (multiply matching parts, add).
  2. Scale: sᵢ ÷ √d_k (d_k = 2 → ÷ 1.414).
  3. Softmax: eˢ each → add → divide each by the total.
  4. Output = Σ wᵢ · vᵢ, component by component.
q = [0,1]; k = [1,0], [−2,−1], [2,0]; v = [2,−1], [4,0], [3,4]; d_k = 2 → scores 0, −1, 0 → scaled 0, −0.707, 0 → e: 1, 0.493, 1 (sum 2.493) → w = 0.401, 0.198, 0.401 → output [0.802+0.791+1.203, −0.401+0+1.604] = [2.797, 1.203].
q = [1,0]; k = [1,0],[0,1],[1,1]; d_k 2 → [.71, 0, .71] → w [.40, .20, .40]; values [1,2],[3,0],[0,4] → [0.99, 2.41].
★ Weights only (no q, k)? Skip to step 4: 0.3·[2,0] + 0.7·[0,2] = [0.6, 1.4]; 0.2/0.5/0.3 on [1,0,2],[0,1,1],[2,2,0] → [0.8, 1.1, 0.9]. Missing weight = 1 − others (0.2, 0.5 → 0.3).
✗ [0, 2] = picked the biggest weight only · [2, 2] = added without weights. Output length = value length.
Q = XW_Q (what the token asks), K = XW_K (what each token offers for matching), V = XW_V (what gets mixed in). Poll 4 "What was Mando searching for?": Q = question, K = log-token keys, V = separate log-token values. Each row of A sums to 1. Self-attention ignores order → add positional encoding PE(pos, 2i) = sin(pos/10000^(2i/d)), PE(pos, 2i+1) = cos(…); position 0 → (0, 1, 0, 1, …). Shapes: X 8×4 · W 4×3 → Q, K, V 8×3 · QKᵀ 8×8. Multi-head = several heads with their own W's, concatenated. Transformer block = multi-head attention + feed-forward + residual + layer norm; GPT uses a causal mask. Attention fixes the RNN bottleneck, runs in parallel, reaches distant words directly.

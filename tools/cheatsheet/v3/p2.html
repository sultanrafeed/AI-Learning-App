5Gradient descent · linear & logistic regressionLecture 4↑ index
Training = finding the bottom of a loss "bowl". The gradient says which way is uphill, so step the opposite way. α (learning rate) = step size.
\(w \leftarrow w - \alpha\,\frac{\partial L}{\partial w}\)  ·  linear model \(h(x) = w_1x + w_0\), loss \(L=\sum_j (y_j - h(x_j))^2\)
\(\frac{\partial L}{\partial w_0} = -2\sum (y-h)\)   \(\frac{\partial L}{\partial w_1} = -2\sum (y-h)\,x\)
w = −0.3, ∂L/∂w = 2.3, α = 0.05 → −0.3 − 0.115 = −0.415.
Data (1,3),(2,5),(3,7), w₀=0, w₁=1: predictions 1,2,3 → errors 2,3,4 → L = 4+9+16 = 29; ∂/∂w₀ = −18, ∂/∂w₁ = −2(2+6+12) = −40; α = 0.05 → w₀ = 0.9, w₁ = 3.0 (loss falls to 12.83).
One-example form (factor 2 inside α): w₀ ← w₀ + α·err, w₁ ← w₁ + α·err·x. w₀=−1.5, w₁=1.5, α=0.05, (x,y)=(5,1): h = 6, err = −5 → w₀ = −1.75, w₁ = 0.25.
Logistic regression: \(h = \sigma(\mathbf{w}\cdot\mathbf{x}) = \frac{1}{1+e^{-\mathbf{w}\cdot\mathbf{x}}}\) · loss (binary cross-entropy) \(L = -[\,y\ln h + (1-y)\ln(1-h)\,]\) · gradient \((h - y)\,x_i\)
w = (0.5, −1, 2) (first = bias, x₀ = 1), x = (1, 1, 0.5), y = 1 → z = 0.5 − 1 + 1 = 0.5 → h = 0.622 → L = −ln 0.622 = 0.474 → bias gradient (0.622 − 1)(1) = −0.378. y = 0, h = 0.8 → L = −ln 0.2 = 1.609.
w₀ = 1, w₁ = 2, example (3, 8), α = 0.1: h = 7, error 1 → w₀ = 1.1, w₁ = 2 + 0.1(1)(3) = 2.3. Logistic z = 1 → p = 0.731; y = 1: loss −ln 0.731 = 0.313; w₁ ← 2 − 0.1(0.731 − 1)(1) = 2.027.
✗ Gradient positive → w goes DOWN. ✗ Forgot α. ✗ Recomputed h with the new w₀ before updating w₁ (compute the error ONCE). ✗ Logistic uses ln, not log₂.
Squared loss is convex (one minimum) → GD works. Too big α overshoots/diverges; too small is slow. SGD / Adam use mini-batches. Threshold 0.5 turns a probability into a class; decision boundary w·x = 0. Linear: MAE/RMSE/R²; logistic: accuracy, precision, recall, F1, AUC. sklearn C = inverse regularisation strength.

Workflow (10 steps): define problem/collect → explore/prepare (encode, scale) → train/test split (e.g. 80/20, test set aside) → choose models + hyperparameter space → tune with k-fold CV on the training set only (score = mean of k folds) → pick best → retrain on full training set → evaluate ONCE on the test set → residual analysis → deploy/monitor. Using test data while tuning = data leakage. Parameters are learned (weights); hyperparameters are set before training (depth, k, α, C).
Learning types: supervised (input–output pairs), unsupervised (patterns, no labels, e.g. clustering), reinforcement (rewards/punishments). Classification = discrete label (spam, COVID +/−, Iris species); regression = number (price, temperature, AUD/USD). i.i.d. = independent and identically distributed. Ockham's razor = simplest consistent hypothesis. Underfit = too simple (bad on train and test); overfit = memorises noise (good train, bad test).
6BkNN · SVM · ensemblesLecture 4↑ index
kNN: copy the majority of the k closest stored examples (no training). SVM: the separating line with the widest "street". Ensembles: many models vote.
kNN query (2,2): A(1,1)+ 1.414, B(3,1)− 1.414, C(2,4)+ 2.000, D(4,4)− 2.828, E(1,3)+ 1.414 → k = 3: A, B, E → +. Manhattan to D = 4. Regression kNN = average of the k neighbours' y. House (k = 3, query 90 m², 2 beds): nearest distances 10, 10.05, 30 → prices 220, 260, 180 → 220. Iris (k = 3) → Setosa.
kNN = instance-based ("lazy"), stores the data, slow prediction, scale features first, sensitive to irrelevant features, odd k avoids ties, small k jumpy/overfit, large k smooth/underfit, weights uniform or 1/distance.
SVM: \(\min \tfrac12\lVert\mathbf w\rVert^2\) s.t. \(y_i(\mathbf w\cdot\mathbf x_i + b)\ge 1\) · functional margin \(y_i(\mathbf w\cdot\mathbf x_i+b)\) · geometric = functional / ‖w‖ · street width \(2/\lVert\mathbf w\rVert\) · classify sign(w·x + b)
w = (0.5, 0.5), b = −2, ‖w‖ = 0.7071. P1 (3,3)+ : 1.5+1.5−2 = 1 · P2 (4,3)+ : 1.5 · P3 (1,1)− : −1×(1−2) = 1 → support vectors = P1, P3 (functional margin exactly 1); geometric 1.414, 2.121, 1.414; width 2.828; new (2,3) → 0.5 > 0 → +1. Dual α₁ = α₃ = 0.25, α₂ = 0.
Soft margin adds C·Σξᵢ: large C = errors expensive → narrower margin, risk overfit; small C = wider margin. Kernel trick: replace x·z by K(x,z) to get non-linear boundaries without mapping explicitly (linear, polynomial, RBF with γ = reach; big γ wiggly). Only support vectors decide the boundary. 7Neurons · perceptron · backprop · parametersWorkshop 5↑ index
A neuron = weighted sum of inputs + bias, then an activation. Training a network = forward pass (compute ŷ), then pass the error backwards to get each weight's gradient.
\(in_j = \sum_i w_{i,j}a_i + w_{0,j}\)   \(a_j = g(in_j)\)  ·  Perceptron: \(w_i \leftarrow w_i + \alpha\,(y - \hat y)\,x_i\) (x₀ = 1 for the bias)
Neuron x = (2, −1), w = (0.5, 1.5), b = 0.25 → z = −0.25 → ReLU 0, σ 0.438, step 0.
Perceptron w = (−0.5, 0.2, 0.4), x = (1,1,1), y = 0, α = 0.1: sum 0.1 ≥ 0 → output 1 (wrong) → w = (−0.6, 0.1, 0.3). Correct output → no change. Single perceptron can do AND/OR, not XOR.
Sigmoid neuron, squared loss: \(\frac{\partial L}{\partial w_i} = -2(y-h)\,h(1-h)\,x_i\)
w = (0.1, 0.4, −0.3), x = (1, 2, 1), y = 1, α = 0.5: z = 0.6, h = 0.646, L = 0.126, ∂L/∂w₁ = −0.324 → w₁ = 0.562.
Backprop spot it: "inputs 1,2 → sigmoid hidden 3,4 → output 5", a₃, a₄, w₃,₅, w₄,₅, w₀,₅ (bias), target y.
\(\hat y = \sigma(w_{3,5}a_3 + w_{4,5}a_4 + w_{0,5})\) · \(\Delta_5 = 2(\hat y - y)\,\hat y(1-\hat y)\) · \(\partial L/\partial w_{3,5} = \Delta_5 a_3\) · \(\Delta_3 = \Delta_5\, w_{3,5}\, a_3(1-a_3)\) · \(\partial L/\partial w_{1,3} = \Delta_3 x_1\)
a₃ = 0.21, a₄ = 0.24, w₃,₅ = 0.5, w₄,₅ = 1, w₀,₅ = 1, y = 1: in₅ = 1.345 → ŷ = 0.7933 → Δ₅ = 2(−0.2067)(0.7933)(0.2067) = −0.0678 → ∂L/∂w₃,₅ = −0.0142 → Δ₃ = −0.0678×0.5×0.21×0.79 = −0.0056. Then w ← w − α·grad.
Lecture example x = (1, 0), y = 1, α = 0.5: a₃ = 0.622, a₄ = 0.574, ŷ = 0.561, loss 0.193; Δ₅ = −0.2165, Δ₃ = −0.0305, Δ₄ = +0.0212; w₃,₅ 0.6 → 0.667, w₁,₃ 0.5 → 0.515, w₂,· unchanged (x₂ = 0).
ReLU hidden, sigmoid out x=(1,2): in₃ = 0.5−0.5+0.1 = 0.1, in₄ = −1+1 = 0 → in₅ = 0.1+0−0.5 = −0.4 → ŷ = 0.401.
★ Sign convention: Book 3 writes Δ = 2(y − ŷ)ŷ(1−ŷ) and updates w ← w + α·aᵢ·Δ. Same result; just stay consistent.
Dense parameters per layer = \((n_{in} + 1)\times n_{out}\) · 4–5–3–2 → 25 + 18 + 8 = 51 · 224×224×3 image → 1000 units = 150,528,000 weights
McCulloch & Pitts 1943. Layers: input, hidden, output; bias = weight on a dummy input a₀ = 1. FFN = no cycles; RNN = feedback. Universal approximation: two layers (first non-linear, second linear) can approximate any continuous function. Vanishing gradient: error signals shrink going back (σ′ ≤ 0.25 per layer; 0.25¹⁰ ≈ 10⁻⁶); ReLU helps. Keras: Sequential → Input → Dense(…, activation) → compile(loss, optimizer='adam', metrics) → fit(epochs, batch_size). Hypothesis space = #inputs, #hidden layers, neurons + activation per layer, #outputs. Epoch = one pass over the data; batch = data per gradient step.
✗ Bias added as w₀ × 1. ✗ ŷ is between 0 and 1. ✗ Watch y = 0 vs 1. ✗ Δ₃ uses a₃(1−a₃), not ŷ(1−ŷ).

Generative model = learns what the DATA look like, p_model(x) ≈ p_data(x), so it can make new samples. Latent variables z = hidden factors (pose, lighting, identity) that explain an observation x.
Supervised: learn x → y from labels · unsupervised: hidden structure from unlabelled data · generative: model the data distribution to generate. Uses: sample generation, outlier detection (train on normal products, flag defects), debiasing datasets.
Autoencoder: x → encoder → small z → decoder → x̂; loss ‖x − x̂‖², no labels. Smaller z = tighter bottleneck, blurrier output. Denoising AE: noisy in, compare with clean. Uses: compression, denoising, anomaly detection (high reconstruction error). Limitation: not good at generating from random codes.
x = (1,0,2), x̂ = (0.5,0,1.5) → loss 0.25+0+0.25 = 0.5.
VAE: encoder outputs μ and σ; \(z = \mu + \sigma\odot\varepsilon,\ \varepsilon\sim\mathcal N(0,I)\) (reparameterisation: lets gradients flow through sampling)
Loss = reconstruction + \(D_{KL}(q(z|x)\,\|\,\mathcal N(0,I))\), \(D_{KL} = \tfrac12\sum(\mu^2 + \sigma^2 - 1 - \ln\sigma^2)\)
μ = 2, σ = 0.5, ε = −1.2 → z = 1.4 · KL(μ=.5, σ=.8) = ½(.25+.64−1+.446) = 0.168 · AE x = (1,0,.5), x̂ = (.8,.1,.4) → 0.06 · KL(μ=1,σ=1) = 0.5 · KL(0,1) = 0 · KL(0, σ=2) = ½(4 − 1 − ln 4) = 0.807 · KL(μ=0.5,σ=1) = 0.125.
Regularisation gives continuity (nearby z → similar output) and completeness (any sampled z → meaningful output). β-VAE (β > 1) → disentangled factors. Generate: sample z ~ N(0,I), decode.
8BGAN · autoregressive · diffusion · compareLecture 9↑ index
GAN: \(\min_G\max_D\ \mathbb E[\ln D(x)] + \mathbb E[\ln(1 - D(G(z)))]\) — D maximises, G minimises
D(x) = 0.9, D(G(z)) = 0.2: ln 0.9 + ln 0.8 = −0.329 · D(real) = 0.8, D(fake) = 0.3 → ln 0.8 + ln 0.7 = −0.580 · equilibrium D = 0.5 → 2 ln 0.5 = −1.386.
G turns noise into fakes; D outputs P(real). Ideal: p_G = p_data, D = 0.5 everywhere. Mode collapse = G makes one kind of output. After training only G is used. GANs have no explicit density.

9Convolution output cell · poolingLecture 7 · key points
A filter (kernel) is a small grid of weights = a "visual question" (is there an edge here?). Slide it over the image; at each place multiply the overlapping numbers and add them up. Big result = pattern found.
Spot it: input grid + kernel, "output[1,0]", "stride", "max / average pooling 2×2 stride 2".
\(z[p,q] = \sum_i\sum_j w_{ij}\,x[p+i,\,q+j] + b\)   (no flip: technically cross-correlation)
  1. output[r, c] → window's top-left at input[r·S, c·S] (S = stride).
  2. Multiply each window cell by the kernel cell on top of it. Skip zeros.
  3. Add everything (+ bias if given) = that output cell.
Window [3 1 3 / 1 1 1 / 2 0 2] × kernel [0 −1 −1 / −1 0 1 / 0 −1 1] → (0−1−3) + (−1+0+1) + (0+0+2) = −2.
Lecture '7' (rows 11111/00010/00100/01000/01000) × diagonal [−1 −1 1 / −1 1 −1 / 1 −1 −1], S1 P0 → 3×3 map [−2 −3 1 / −2 3 −2 / 1 −1 −1]; out[1,1] = 3 (best match).
X = [1 2 0 1 / 0 1 3 1 / 2 1 0 0 / 1 0 1 2], K = [1 0 / 0 −1] → [0 −1 −1 / −1 1 3 / 2 0 −2] (top-left − bottom-right of each 2×2).
★ Kernel [1, 0, −1] in every row = left column sum − right column sum (vertical edges). [−1 −1 −1 / 0 0 0 / 1 1 1] = horizontal edges. Input only 0/1 → count 1s under +1 minus 1s under −1.
Max pool = biggest in the window · Average pool = sum ÷ (K×K) · no parameters · pool size K → stride K by default
[1 3 2 4 / 5 6 1 2 / 7 2 9 0 / 1 8 3 4], 2×2 stride 2 → max [6 4 / 8 9], average [3.75 2.25 / 4.5 4]. Lecture: rows (230,135,0,0),(231,146,0,0),(207,136,0,0),(163,120,0,0) → max [231 0 / 207 0]. 512×512 → 256×256. Averages of 4 always end .00 .25 .50 .75.
✗ [0,1] = row 0, column 1 = top-RIGHT block. ✗ Stride 2 → window jumps 2 (no overlap for 2×2). ✗ Don't flip the kernel.
Why convolution (not dense): dense layers flatten (lose the 2-D neighbourhood) and parameters explode; convolution = locality + weight sharing + hierarchy (edges → parts → objects). ReLU after conv (max(0,z)). Deeper layers: larger receptive field, more abstract features.

12IoU · NMS · detection · CNN architecturesLecture 7 · key points
IoU = how much two boxes overlap (0 none, 1 identical). NMS removes duplicate boxes on the same object: keep the most confident, delete its same-class near-copies.
overlap w = min(x₂) − max(x₁), h = min(y₂) − max(y₁) (≤ 0 → no overlap) · \(IoU = \frac{I}{A + B - I}\)
A (0,0)–(6,4), B (2,0)–(8,4): areas 24, I = 4×4 = 16, U = 32 → 0.50; rule "suppress if > 0.40" → suppress B.
A (1,2)–(7,6), B (4,3)–(9,8): w 3, h 3, I 9, A 24, B 25, U 40 → 0.225 · (1,1)–(5,5) vs (3,2)–(7,6): 6/26 = 0.231 · (0,0)–(4,4) vs (2,2)–(6,6): 4/28 = 0.143 · (0,0)–(10,10) vs (5,0)–(15,10): 50/150 = 0.333.
  1. Sort boxes by score; keep the top one.
  2. Delete every lower box of the SAME CLASS with IoU(top, box) > threshold (≥ if the rule says ≥).
  3. Take the next highest remaining box; keep; repeat.
P .92, Q .85, R .70; IoU(P,Q) = .40, IoU(P,R) = .55. Rule "> 0.40" → keep P, Q, drop R. Rule "≥ 0.40" → only P. Cars A .90, B .80, C .75 + person D .70: IoU(A,B) = 9/23 = .39 keep, IoU(A,C) = .75 drop, D never compared → A, B, D.
✗ Union = A + B − I (not A + B). ✗ Box inside box: IoU = small/big. ✗ Centre format (x, y, w, h) → corners x ± w/2 first. ✗ IoU exactly = threshold with ">" → NOT suppressed. ✗ NMS across classes = FALSE.

15Bayes' rule · directions · independence · building a BNLecture 11
\(P(C|E) = \frac{P(E|C)\,P(C)}{\sum_c P(E|c)P(c)}\) — posterior = likelihood × prior ÷ evidence
Disease prior 1%, test 90% sensitive, 5% false positives: P(+) = .009 + .0495 = .0585 → P(d|+) = 0.154. Prior 5%, 80%, 10% → 0.04/0.135 = 0.296. Spam 0.4×0.3 = .12 vs ham 0.6×0.05 = .03 → 0.8. Meningitis 0.7 × (1/50000) / 0.01 = 0.0014.
DirectionMeansExample
Causalcause → effect, P(effect | cause) — what we usually KNOWP(S | D), P(alarm | burglary)
Diagnosticeffect → cause, P(cause | effect) — what we WANTP(D | S), P(burglary | alarm)
Independent: \(P(X,Y)=P(X)P(Y)\) · Conditionally independent given Z: \(P(X|Y,Z) = P(X|Z)\)
BN = DAG (no cycles) · node = random variable · arrow parent → child · each node has a CPT P(X | parents) (root: P(X)) · child node = has a CPT given its parents · edge = association between two nodes · arrow = the parent→child link. A node with k Boolean parents needs 2ᵏ rows (3 parents → 8). Burglary: 1+1+4+2+2 = 10 numbers vs 2⁵−1 = 31. Given its parents, a node is independent of its other predecessors (J ⊥ B | A). B and E are independent until A is observed.
Building: chain rule P(x₁…xₙ) = Π P(xᵢ | x₁…xᵢ₋₁) → choose variables → order causes before effects (most compact) → pick a minimal parent set for each node → draw arrows → fill CPTs. Inference: query X, evidence e, hidden Y: P(X|e) = α Σ_y P(X, e, y). Uncertainty: partially observable (drone in fog), non-deterministic (trading agent), both (city driving).
